# Immunization and Maternal & Child Health Analytics (Rwanda)

Django web application with an AdminLTE dashboard. Group 15, Web Technologies and API Services (Django midterm project).

## What it does
Tracks child immunization and antenatal care by district in Rwanda and flags districts below the coverage target.

- Real data: districts, populations and child counts (NISR, Fifth Population and Housing Census 2022); national vaccine coverage estimates (WHO-UNICEF WUENIC, 2014-2025).
- Simulated data: facilities, children, immunization records and antenatal visits (individual health records are not public). They are generated by `python manage.py seed_data`.

## Apps
- `health_data`: districts, health facilities, vaccines, children (CRUD for children, district pages)
- `coverage`: immunization records (CRUD), maternal visits, national coverage benchmark, dashboard

## Run it
```
python -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
Open http://127.0.0.1:8000/ (dashboard) and http://127.0.0.1:8000/admin/ (Django admin).

The submitted `db.sqlite3` already contains the data. To rebuild it from scratch:
```
python manage.py migrate
python manage.py load_districts
python manage.py load_child_counts
python manage.py load_vaccines
python manage.py load_national_coverage
python manage.py seed_data
```
